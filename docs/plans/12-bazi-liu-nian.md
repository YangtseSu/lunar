# 计划 12 — 流年 / 流月 / 小运

Status: 待实施 · Priority: P2 · Depends: 10（先有大运）

## 现象

`lunar bazi -g` 印大运十步，但每步**只有干支与岁数区间**。传统排盘里每一步大运下
还挂着十年的**流年**、十二个**流月**，以及逐年一步的**小运**；引擎
（`DaYun::liu_nian` / `LiuNian::liu_yue` / `DaYun::xiao_yun`）全部已实现，本仓库
未暴露。

```console
$ lunar bazi 1990-06-15T10:30 -g 男 | tail -1
大运: 8-17 癸未 / 18-27 甲申 / 28-37 乙酉 / 38-47 丙戌 / 48-57 丁亥 / 58-67 戊子 / 68-77 己丑 / 78-87 庚寅 / 88-97 辛卯
```

引擎侧实测（1990-06-15 10:30 男，索引 2 的大运 `18-27 甲申`）：

```
流年 乙未  26岁  旬空=辰巳
   流月 戊寅 正 / 己卯 二 / 庚辰 三 / 辛巳 四 / 壬午 五 / 癸未 六
        甲申 七 / 乙酉 八 / 丙戌 九 / 丁亥 十 / 戊子 冬 / 己丑 腊
流年 丙申  27岁  旬空=辰巳
   流月 庚寅 正 / 辛卯 二 / 壬辰 三 / 癸巳 四 / 甲午 五 / 乙未 六
        丙申 七 / 丁酉 八 / 戊戌 九 / 己亥 十 / 庚子 冬 / 辛丑 腊
```

注意两点实测事实：

- **流月 的月名是农历月序，不是公历月**：`正 二 三 … 十一 冬 腊`，十二月
  印作 `腊`、十一月印作 `冬`（引擎 `LiuYue::month_in_chinese` 如此）。
- **小运 从时柱起、逐年一步**，不是十年一步：
  `小运: 18岁-2007年 辛亥 / 19岁-2008年 壬子 / … / 27岁-2016年 庚申`
  （`XiaoYun` 的 `age()` 与 `year()` 是**两个不同字段**，输出时不可互换。）

## 归属

**本仓库未暴露的能力**（引擎已实现）。

## 目标行为

### A. 流年 / 流月：新增 `-y` 查询

```
$ lunar bazi 1990-06-15T10:30 -g 男 -y 2015
八字: 庚午 / 壬午 / 辛亥 / 癸巳
…
大运: 8-17 癸未 / 18-27 甲申 / …
流年 乙未  26岁  旬空 辰巳
流月 戊寅(正) / 己卯(二) / 庚辰(三) / 辛巳(四) / 壬午(五) / 癸未(六) / 甲申(七) / 乙酉(八) / 丙戌(九) / 丁亥(十) / 戊子(冬) / 己丑(腊)
```

1. `-y <公历年>` 是**新输入语义**：与大运（排盘产物）不同，流年是「问某一年」。
   不给 `-y` 时**不印**流年 / 流月——十步 × 十年 = 一百行，默认印出来不可读。
2. 该年在哪一步大运上，由引擎 `LiuNian` 的 `age()` 定位；跨步或落在起运之前
   时印一行说明，不静默取邻近值。
3. 需 `-g`（无性别无大运即无流年）；缺 `-g` 时 `-y` 印一行说明而非报错。
4. 流月用**农历月名**，与 `bazi` 的 `农历:` 行同一套名字。

### B. 小运：默认不印

小运逐年一步、十步大运各十步，量级与流年相同，故：

1. 不默认印，**跟随 `-y`**：给 `-y` 时印该年所属的小运一步。
2. 若日后要做「印全部」，另立计划。

## 实施步骤

1. `src/calendar.rs`：加 `liu_nian(&DaYun, ...) -> Vec<LiuNian>` 与
   `liu_yue(&LiuNian) -> Vec<LiuYue>` 的包装（仅排版，故可为一行转发，
   但需按仓库「无意义包装即死代码」的规则复核）。
2. `src/main.rs`：`Command::Bazi` 增 `-y/--year <年>`，与 `-g` 无依赖关系。
3. `src/commands/bazi.rs`：`BaziArgs.year`；`write_chart` 增 `year: Option<i32>`；
   -y 的年份经 `calendar::solar` 校验（1–9999），越界报 `YearOutOfRange`。
4. 测试（`tests/documented_examples.rs`，四个）——见验收。
5. 文档：README、AGENTS.md 契约、parity 登记。

## 取舍（登记于 `docs/parity.md`）

- **流年需显式 `-y`**，不默认全印：一百行默认输出不可读，且「问哪一年」是
  另一个问题。
- **小运跟随 `-y` 同行印出**，不单独展开。
- **流月用农历月名**（`正…冬 腊`），与 `农历:` 行同源，不改用公历 1–12。

## 验收

```console
$ lunar bazi 1990-06-15T10:30 -g 男 -y 2015 | tail -2
流年 乙未  26岁  旬空 辰巳
流月 戊寅(正) / 己卯(二) / 庚辰(三) / 辛巳(四) / 壬午(五) / 癸未(六) / 甲申(七) / 乙酉(八) / 丙戌(九) / 丁亥(十) / 戊子(冬) / 己丑(腊)
```

测试：

- `a_year_prints_its_luck_year_and_months` —— 2015 得 `乙未 26岁`，流月十二项。
- `a_year_without_a_gender_says_so` —— `-y` 无 `-g` 时印说明，不报错。
- `a_year_outside_the_range_is_reported` —— `-y 0` / `-y 10000` 报
  `年份 … 超出支持范围`。
- `the_luck_year_sits_in_the_step_that_owns_it` —— 2015 的岁数落在 `18-27 甲申`
  这一步内；起运前的年份（如 1996）印说明而非邻近值。

## 非目标

- **小运全量输出**（本计划只做「该年那一步」）。
- **流日**（引擎无此物）。
- **真太阳时**（计划 13 只做文档声明）。
